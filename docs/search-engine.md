# 文件索引与搜索

桌面进程持有内存索引、执行查询并保存快照；Windows 服务只负责卷元数据访问。服务和桌面复用同一个 exe，服务由 SCM 以 `--index-service` 启动。

## 卷身份与恢复

服务的 `ListVolumes` 返回盘符、Volume GUID 和卷序列号。盘符是挂载位置，不能作为持久卷身份。

快照按 GUID 与序列号命名为 `volume-<identity>-<serial>.dat`。恢复到新盘符时重新映射根名称和目录项中的卷标识，文件引用不变。盘符被不同卷复用时不能沿用原盘符的检查点。服务打开 GUID 卷路径，并核对发现时的身份。

一个卷的 Journal ID 或位点失效，仅重建该卷；其它卷继续补读。当前进程已加载的离线卷数据可以保留；未挂载卷的快照保留在磁盘，冷启动不会将它误绑定到占用旧盘符的新卷。新增卷在重新连接并发现卷时纳入。

## 数据模型

索引目录项保存完整文件 FRN、完整父目录 FRN、名称池偏移、卷标识和类型优先级。父目录回溯同时检查卷、FRN 代次和目录属性，避免 MFT 记录复用后把旧子项连接到新目录。

同一 FRN 可对应多条目录项。精确目录项身份是 `(卷, FRN, 父目录 FRN, 名称)`，同名硬链接位于不同父目录时保持独立。删除使用带父目录的原名字；重命名旧名事件删除旧目录项，新名事件增加新目录项，不覆盖剩余硬链接。

名称池和条目数组采用紧凑布局，条目内存大小 32 字节。快照明确逐字段编码，不能把 Rust 结构体内存直接作为格式。快照版本为 3。

注意：正确表达已枚举的链接不等于 MFT/USN API 一定完整枚举了所有硬链接名字；真实卷上的硬链接发现完整性仍需专项验证。

## 全量建库

1. 记录枚举开始前的 Journal ID 和 NextUsn。
2. 创建暂存代次，保留旧代次供查询。
3. 全量枚举 MFT，不以开始时 USN 限制 HighUsn，避免扫描期间被修改的已有文件被过滤。
4. 每 2048 条记录形成管道批次，桌面串行写入暂存索引。
5. 从开始位点补读扫描期间的 USN 变更。
6. 应用忽略规则并完成协调，发布该卷新代次和检查点。
7. 从已处理位点继续跟随。

扫描中断、客户端断开、服务停止或补读失败时，不发布未完成代次。MFT 枚举只将 ERROR_HANDLE_EOF 视为正常结束，不能把其它 I/O 错误伪装成扫描完成。

## 增量与检查点

补读和实时跟随使用相同的事件模型。实时批次在事件之后携带检查点，桌面应用完批次才能推进位点。读取失败或下游写入失败不能产生成功检查点。

Journal ID 改变、位点早于 FirstUsn 或超出 NextUsn 时重新同步；不能悄悄跳到当前末尾。监控停止会结束当前会话，桌面退避重连后补读或重建。

索引更新由桌面索引协调线程串行执行。查询不写索引；快照只包含已经发布的代次。尚未到达父目录的条目保留为暂时无法解析路径的目录项，后续父目录到达后可以解析。

## IPC 与背压

协议版本为 4，帧为长度前缀加类型化二进制消息。解码检查边界、UTF-8 和尾随数据，接收帧有大小上限。协议与快照版本独立演进。

扫描及各卷跟随共享串行写端，整帧不能交错。同步管道与固定批次提供背压，不使用无界元数据消息队列。扫描在页面间检查取消/写入失败，服务停止会取消阻塞的同步 I/O。

服务只处理一个桌面会话；客户端断开后释放卷任务，返回 accept 等待。桌面退出期间依靠 Windows USN Journal 保存变更，不另维护服务端索引。

## 查询

查询按分号分词，所有关键词必须命中；含路径分隔符的词匹配路径，其余匹配文件名。默认大小写不敏感。

单查询线程加单待执行槽位避免输入积压。查询按 4096 个槽位分块读取，块间释放读锁并检查取消。结果为稳定 Top-K：精确名称、前缀、子串依次排序，之后比较类型偏好、名称和路径。

查询不扫描真实目录，不逐条调用存在性检查，也不懒删除。展示辅助信息在后台获取；打开结果使用当前用户的 Shell 权限。

## 持久化

每个卷分别保存索引和已应用检查点。保存写临时文件、刷新内容、保留上一代，再原子替换。加载首先校验长度和校验和，当前文件损坏时尝试 `.bak`，无法恢复则重建。

USN 是恢复来源，不额外实现自建 WAL。Journal 保留期不足时允许重建。大量变更及有序退出会保存快照；不能假设进程崩溃前最后一批已经落盘。

## 测试范围

核心单元测试覆盖目录关系、记录代次、同名硬链接、卷盘符映射、快照损坏恢复、协议、查询调度和排序。

实际 NTFS/USN、服务启停和 MSI 生命周期需要 Windows。跨目标类型检查和成功链接只证明编译能力，不证明这些系统行为已运行通过。
